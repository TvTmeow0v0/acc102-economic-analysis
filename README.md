# A Python-Based Comparison of GDP Growth, Inflation, and Unemployment in China, the United States, Japan, and India

## 1. Project Overview
This project uses Python to compare three important economic indicators—GDP growth, inflation, and unemployment—across four countries: China, the United States, Japan, and India.

The purpose of the project is to provide a simple and clear comparison of economic performance and stability in these countries.

## 2. Analytical Problem
The project investigates how GDP growth, inflation, and unemployment differ across selected countries and what these differences may suggest about their economic conditions.

## 3. Intended User
The intended users are business students and general readers who want an accessible overview of economic conditions in selected countries.

## 4. Dataset
The dataset contains country-level economic indicators for the period 2019–2023.

Variables included:
- Country
- Year
- GDP_growth
- Inflation
- Unemployment

## 5. Python Methods Used
This project uses:
- `pandas` for data loading and cleaning
- `matplotlib` and `seaborn` for visualisation
- grouping and descriptive comparison of indicators across countries

## 6. Key Outputs
The notebook includes:
- GDP growth comparison chart
- Inflation comparison chart
- Unemployment comparison chart
- Average indicator comparison table and bar chart

## 7. Main Findings
- India and China showed stronger GDP growth over most of the selected years.
- The United States had a clear inflation increase in 2022.
- Japan showed relatively low and stable inflation.
- Unemployment patterns differed across countries, with greater fluctuation in some cases.

## 8. How to Run the Project
1. Download or clone this repository.
2. Make sure `economic_data.csv` is in the same folder as the notebook.
3. Install the required packages from `requirements.txt`.
4. Open and run `economic_analysis.ipynb`.
